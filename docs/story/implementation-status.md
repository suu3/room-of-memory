# 구현 현황: 페이즈 · 조사 차수 · 남은 에셋 (설계서 v4 기준)

개발 설계서 v4(2026-09-25)를 코드에 옮긴 결과와 남은 일. 설계서의 장 번호를 그대로 쓴다.
대본·흐름의 단일 소스는 여전히 `content/*.yaml`이다 (`.claude/rules/visual-novel.md`).

2026-10-02에 코드·콘텐츠와 대조해 고쳤다: 3차 조사 목록, 4페이즈 필수 조사, 들어온 에셋, 번역 현황.

## 1. 진행 상태 모델

페이즈는 **저장하지 않고 진행에서 파생된다** (`src/data/story-phase.ts`의 `storyPhaseOf`).
설계서 1-3은 `phase`를 저장하라고 적었지만, 파생이면 콘텐츠가 바뀌어도 옛 저장본의
페이즈가 실제 진행과 어긋날 일이 없다. 저장하는 것은 "무엇을 몇 차까지 봤는가"와
문·물건뿐이다.

| 전이 | 판정 (코드) |
| --- | --- |
| intro → p1 | `introDone` (전등 스위치) |
| p1 → turning | 1차 조사 전부 (`collected`가 목표 수) |
| turning → p2 | `doorOpened` (라디오 2차 = 생존자 방송 뒤에만 열린다) |
| p2 → p3 | `from: p2`이고 곁가지가 아닌 조사 전부 |
| p3 → p4 | 안방 문(`living-parents`)이 열림 |
| p4 → resolve | `from: p4` 필수 조사 전부 (연구 일지 · 출입증 · 액자 2차) |
| resolve → ending | `endingStarted` (가방·앰플·배트를 다 챙긴 뒤 현관문. `angle-turn` 잠금은 뺐다) |

설계서 1-3의 플래그는 전부 파생값이다 (`src/store/memory-room.ts`):

| 설계서 | 셀렉터 | 근거 |
| --- | --- | --- |
| `heardSurvivorBroadcast` | `selectHeardSurvivorBroadcast` | 라디오 2차 |
| `momChatRead` | `selectMomChatRead` | 폰 2차 |
| `logoMatched`, `dadHintRead` | `selectSinkHintRead` | 컴퓨터 3차 (라온 로고 고르기 → 메일이 한 화면). 컴퓨터 3차 자체는 세면대 바닥의 배지(`selectBadgeSeen`) 뒤에 열린다 |
| `stillBeatDone` | `selectStillBeatDone` | resolve 도달 |
| `deadline` | `selectDeadline` | p2 이후 = 4. 방송부터 현관까지 하루 안의 일이라 줄지 않는다 |

조사 차수는 셋까지다: `collected`(1차) · `revisited`(2차) · `rechecked`(3차). 3차가 있는 기억은
셋이다: 컴퓨터(p3, 라온 로고 고르기), 가방과 앰플(resolve, 떠나기 전에 챙기기).
저장 버전은 3으로 올렸다. 옛 저장본은 모르는 id만 버리고 그대로 이어진다.

## 2~3. 공간 · 페이즈별 흐름

| 페이즈 | 무엇이 열리나 | 어디 |
| --- | --- | --- |
| p1 | 문제집(이름 · 자기소개) → 강도 0(성적표) → 강도 1(게임기·공) → 강도 2(액자·폰) → 달력(폰 뒤)·창문(강도 2 뒤) → 라디오 | `memories.yaml`의 `unlockAfter` |
| turning | 빨간 라디오 → 생존자 방송 컷씬 → 방문 금빛 | 라디오 `phase2.cutscene` |
| p2 | 가방·냉장고 위칸·신발장·카드·컴퓨터(로그인 0812) → 폰 2차(엄마 대화방) | `from: p2` |
| p3 | 앰플 → 세면대 마개를 뽑아 물 빼기(`sinkDrained`) → 바닥의 출입증 배지(단서 `raon-badge`: 확대 화면 + 한 줄) → 컴퓨터 3차(라온 로고 고르기 · 아빠 메일 힌트) → 거꾸로 꽂힌 책 → 하부장 다이얼 407 → 안방 열쇠 | `from: p3`, `VISIT_AFTER_DISCOVERY`, 퍼즐 `sink-dial` |
| p4 | 연구 일지(서류 순서 맞추기. 소집 공지는 그 조각 하나다) · 출입증 → p4-close → 액자 2차 → 정적 비트 | `from: p4`, 액자 `phase2.cutscene` |
| resolve | 챙길 것 셋이 동시에 금빛(순서 자유): 가방 3차(`duffel-take`) · 앰플 3차(`ampoule-pickup`) · 배트(`bat-grip`) → 셋 다 챙기면 혼잣말 "나가자." → 현관문 | `from: resolve`, `packedForExit` |

- 1페이즈의 닫힌 방문과 꺼진 컴퓨터, 화장실 칫솔컵, 힌트 전의 하부장은 누르면 혼잣말
  한 줄이 흐른다 (`RemarkLine`, 스토어의 `remark`).
- 게임기·공의 2차는 곁가지(`side: true`)로 남겼다. 피아노도 곁가지이고 풀면 한 줄이 흐른다.
- `farewell` 컷씬, `radio-voice`, 폰 1019 잠금(`phone-lock` 미니게임째)은 삭제했다.
- 거실은 부엌과 현관 홈까지 한 공간(`living`)이다 (2026-10-01 확장). 왜 그 배치인지는
  `docs/models/living-room.md`.

## 7. 엔딩 구성 명세 (영상)

31초. 대사 없음. 도해의 얼굴이 나온다 (차 뒤에 숨는 컷, 벽에 기대 쉬는 컷, 체육관 문간의
클로즈업). 체육관의 생존자도 얼굴이 보인다. 영상 파일은 들어와 있다
(`public/assets/video/ending-film.mp4`, `ASSETS`의 `endingFilm`).

1. 현관문을 열고 복도로 나간다.
2. 배트로 좀비를 헤치며 싸운다. 차 뒤에 숨어 살피고, 밤에는 벽에 기대 쉰다.
3. 은강고 교문을 지나 체육관에 닿는다. 문간에 선 도해의 클로즈업. 포수의 손이 미트를
   탁탁 친다. 안경 쓴 생존자가 돌아보며 웃는다.
4. 예고: 도해가 꺼낸 앰플 앞에서 건너편의 손이 멈춘다.
5. 타이틀 카드 ("기억의 방").

## 11. v4.1 추가분 (개발설계_추가분_v4.1)

v4.1이 v4보다 우선한다. 바뀐 것만 적는다.

### 톤

부모님 대사·문자·메일에서 물결과 이모지를 뺐다. 웃음은 "하하하!"로 쓴다. 엄마 7:12 문자는
"도해야 오늘 학교 끝나면 부활동 하지 말고 바로 집에 와. 딴 데 가지 말고", 아빠 메일(컴퓨터
3차)은 "선반 정리 좀 해라."다. 하부장 번호를 메일이 직접 말하지 않는다.

### 3D 인스펙트

집어 든 물건을 살펴보는 판 하나(`InspectTurntable` + `InspectView`)를 물건마다 모양·면 그림·
**손이 하는 일**을 바꿔 쓴다 (`src/components/canvas/inspect-objects.ts`). 처음엔 전부 "돌려서
뒷면"이었는데 같은 트릭이 넷이라 셋을 갈랐다: 뒤집기는 문제집 하나만 남기고, 쪽지는 펼치고,
책은 장을 넘기고, 출입증은 각도 수수께끼다 (기울여 빛을 받는 한 각도에서만 홀로그램 로고가
떠오른다). 면 그림은 코드로 그리고, 아래 그림 파일이 들어오면 그 위를 덮는다 (없어도 동작한다).

| 물건 | 쓰는 곳 | 손이 하는 일 | 찾을 것 | 그림 파일 (선택) |
| --- | --- | --- | --- | --- |
| 문제집 | 단서 `workbook` (1페이즈) | 돌리기 | 뒤표지의 이름 | 기존 |
| 카드 밑의 쪽지 | `card-flip` (카드 2차) | 위로 끌어 펼치기 | 안쪽의 엄마 메모 | 없음 (코드 그림: 글씨가 언어를 따른다) |
| 보냉 케이스 → 앰플 | `ampoule-case` (앰플 2차) | 돌리기 | 옆면의 빈 슬롯 → 라벨의 로고 | `mg-ampoule-label.webp` |
| 거꾸로 꽂힌 책 | 단서 `shelf-book` (컴퓨터 3차 뒤) | 장 넘기기 | 세 장째 귀 접힌 쪽에 끼워 둔 쪽지의 세 자리(`SINK_DIAL_CODE`) → `sink-code` 발견 | 없음 (쪽지는 코드로 그린다) |
| 출입증 | `id-card-flip` (출입증 2차) | 돌리고 기울이기 | 사진 위 홀로그램 씰의 라온 로고 (한 각도에서만) | `mg-id-card-{front,back}.webp` |

`ampoule-pickup`(씬 안 canvas 판)은 떠나기 전 앰플 3차가 쓴다. 3페이즈의 `ampoule-case`는 앰플을 들여다보고 내려놓고(서랍은 닫힌 채), 마지막에 서랍에서 집어 든다.

### 4페이즈

`not-a-trip`을 지웠다. 연구소 소집 공지는 서류 조각 하나(10월 16일)가 됐다. 안방 필수 조사는
연구 일지(`papers-order`: 날짜순 네 조각) + 출입증(`id-card-flip`) 둘이고, 둘을 마치면
"…이게 답일지도 몰라." → 액자 2차 → 정적 비트다. 서류 조각 본문(`minigame.papersOrder.pieces`)은
임시 문안이다. 대사_3-4페이즈가 오면 교체한다.
